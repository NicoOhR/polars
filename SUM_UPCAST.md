# Small Integer Sum — Upcast Optimization

## Explanation

For small integer types (Int8, UInt8, Int16, UInt16), `Series::sum_reduce()` in `series/mod.rs` allocates a full new array by calling `self.cast(&Int64)`, then runs `sum_reduce()` on that Int64 series. That vtable-dispatches through `SeriesTrait` to the `impl_dyn_series!`-generated `SeriesWrap<Int64Chunked>::sum_reduce()`, which calls `ChunkAggSeries::sum_reduce` on the inner `ChunkedArray`, which folds over `PrimitiveArray<i64>` chunks via `wrapping_sum_arr`, accumulating into an i64. The allocation exists solely to widen the element type before the fold — the fold itself never needed it.

The proposed change replaces the cast branch in `series/mod.rs` with a call to a new `cast_sum_reduce()` on `SeriesTrait`, which dispatches to a new `cast_sum_reduce` in the `ChunkAggSeries` blanket impl. That impl calls `cast_sum()`, a free function that iterates directly over the small-type chunks and folds into an i64 accumulator using `AsPrimitive<i64>` per element, with validity handling mirroring `wrapping_sum_arr`. No intermediate array is allocated.

Four places need changes beyond `series/mod.rs`: `series_trait.rs` needs the new `cast_sum_reduce` method with a `polars_bail!` default; the `ChunkAggSeries` blanket impl in `aggregate/mod.rs` needs the method implemented and `T::Native: AsPrimitive<i64>` added to its where clause; the `impl_dyn_series!` macro in `floats.rs` needs a line delegating `SeriesTrait::cast_sum_reduce` to `ChunkAggSeries::cast_sum_reduce`, matching the pattern already used for `sum_reduce`; and `polars-compute/src/sum.rs` is where the actual per-chunk kernel (`upcast_sum_arr` or a generalized `sum_arr_as`) should live to keep the low-level array logic out of `polars-core`.

## Execution Traces

### Old path — small integer types (Int8, UInt8, Int16, UInt16)

```
Series::sum_reduce()                            [series/mod.rs]
  self.cast(&Int64)                             <- allocates full new i64 array
  Series::sum_reduce() on Int64 series
    self.0.sum_reduce()                         [SeriesTrait vtable]
      SeriesWrap<Int64Chunked>::sum_reduce()    [generated by impl_dyn_series!]
        ChunkAggSeries::sum_reduce(&self.0)     [aggregate/mod.rs]
          ChunkAgg::sum()                       [fold per PrimitiveArray<i64> chunk]
            wrapping_sum_arr(array)             [polars-compute/sum.rs]
              fold &[i64] -> i64
```

### Proposed path — small integer types

```
Series::sum_reduce()                              [series/mod.rs]
  self.0.cast_sum_reduce()                        [SeriesTrait vtable — no allocation]
    SeriesWrap<Int8Chunked>::cast_sum_reduce()    [generated by impl_dyn_series!]
      ChunkAggSeries::cast_sum_reduce(&self.0)    [aggregate/mod.rs]
        cast_sum(array)                           [fold per PrimitiveArray<i8> chunk]
          upcast_sum_arr(array)                   [polars-compute/sum.rs]
            fold &[i8] -> i64  (AsPrimitive<i64> cast per element)
```

### Unchanged path — all other types (e.g. Int64, UInt64, Float32)

```
Series::sum_reduce()                            [series/mod.rs]
  self.0.sum_reduce()                           [SeriesTrait vtable]
    SeriesWrap<Int64Chunked>::sum_reduce()       [generated by impl_dyn_series!]
      ChunkAggSeries::sum_reduce(&self.0)        [aggregate/mod.rs]
        ChunkAgg::sum()                          [fold per PrimitiveArray<T> chunk]
          wrapping_sum_arr(array)                [polars-compute/sum.rs]
            fold &[T] -> T
```
